# IIT Search Engine

**SPL-1 Project — Institute of Information Technology, University of Dhaka**

## Overview

IIT Search Engine is a Java-based domain-specific Information Retrieval system
designed to search public or supervisor-authorized IIT documents.

The project focuses on manually implementing the core components of a classical
search engine, including text preprocessing, indexing, query processing,
searching, ranking, and result retrieval.

## Planned Core Features

- Text preprocessing
- Inverted index
- Positional postings
- Keyword search
- Boolean AND/OR search
- Phrase search
- TF-IDF based ranking
- Top-K result retrieval
- Result snippets
- Index persistence
- Search and performance statistics

## Technology

- Java
- IntelliJ IDEA
- Git
- GitHub

Core Information Retrieval algorithms will be implemented manually without
search-engine frameworks such as Lucene, Elasticsearch, or Solr.
