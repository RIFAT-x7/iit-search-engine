IIT Search Engine

Search mode

Keyword limits require JavaScript. Without it, searches remain unrestricted. This limit does not apply to phrase or Advanced Search.

Basic Keyword Search accepts ordinary multiword queries: any searchable term may match, with results ordered by relevance. Exact Phrase Search matches consecutive words under normalization, including stop words. Advanced Search uses explicit Boolean conditions and returns matches in filename order, without relevance ranking. Without JavaScript, enter a manual AND/OR expression here: AND before OR. Use single searchable words; stop-word operands, parentheses and NOT are not supported.

Advanced Search groups

Every AND word in a group must match the same document, without needing to be adjacent. OR separates alternative complete groups. Results are in filename order. Use one word of ASCII letters or digits per input, without punctuation or stop words. Repeat shared conditions in each group. For computer with either java or python, use computer AND java OR computer AND python. AND is evaluated before OR; no parentheses, NOT, wildcards or metadata fields are supported.
